【1】結論

1. 1投稿を2つに分ける。1本目＝フック（短い）、2本目＝返信欄に本文（長い）
2. 1本目にURLを貼らない
3. 1本目で「持ち帰れる数字か式」を予告する
4. 2本目の最後を質問で終える
5. 1日3本。朝7時・昼12時・夜21時

以下、理由と書き方です。


【2】なぜ2つに分けるのか

Threadsは1本目の数行だけを見て、配るかどうかを決めています。

長い本文を1本目に置くと、読者はそこで読み終えるかスクロールします。
どちらも「最後まで見られなかった投稿」として扱われ、配信が止まります。

分ければ1本目は3行で読み終わる。読み切られた投稿として扱われ、
続きが気になった人が返信欄を開く。Threadsは返信欄が開かれた回数も見ています。

これだけで表示数が40倍変わりました。


【3】1本目の書き方

2〜3行。50字以内。URLなし。絵文字なし。ハッシュタグなし。

型は2つだけ。
①常識をひっくり返す断定（1行）
②数字か式が出てくることの予告（1〜2行）

46万回いった文です。そのまま載せます。

　損益分岐点を出せないまま店を開ける人が、まだ多いです。
　式はひとつだけで、紙1枚で出ます。
　出し方を書きます。

1行目で断定し、2行目で「式がある」「紙1枚」と予告し、3行目で引いています。

効いた言い回し（そのまま使えます）
・「〜と思われていますが、違います。」
・「〜していない人が、まだ多いです。」
・「〜したら、〜になりました。」
・「式はひとつだけです」「3つあります」「紙1枚で出ます」

1行目でやってはいけないこと
・業界用語を置く（読み手の99%は業界の外です）
・疑問文にする（断定してください）
・絵文字（伸びた投稿に1つも入っていません）
・URL（そこで思考が止まります）


【4】2本目の書き方

250〜320字。①②③の3点か、計算をひとつ。

必ず入れるものが2つあります。

ひとつ目は、実際の数字か計算式。

　固定費 ÷ 粗利率 ＝ 損益分岐点売上
　固定費が月180万、原価30%なら、180 ÷ 0.7 ＝ 約257万
　営業26日で割ると、1日あたり約10万

ここまで書くと、読んだ人は自分の数字を入れ始めます。それが滞在時間になります。

ふたつ目は、最後の1行を質問にすること。

　あなたの店のFL、いま何%ですか。

46万回いった投稿でも、返信率は0%。Threadsの判定は「低い」でした。
表示が伸びても、返信が付かないと次が伸びません。
Threadsは返信をいちばん重く見ています。ここがいちばん費用対効果の高い1行です。


【5】核心：専門家の外に出す

ここがいちばん大事です。

伸びた投稿と伸びなかった投稿で、見た人の中身が違いました。

損益分岐点（式がある）460,650回
　→ 見た人の興味：猫・カフェ・筋トレ・旅行・美容

潰れる店は味で潰れない 59,495回
　→ 見た人の興味：カフェ・飲食店経営・飲食店・グルメ

ルールを増やすと組織が弱くなる 10,441回

伸びたほうだけ、業界の外に出ています。
2番目は内容は良いのですが「飲食に興味がある人」の中で止まりました。
3番目は意見としては正しいのですが、持ち帰れるものがないので止まりました。

判定基準はこれだけです。

　その話は、業界を知らない人が読んで、自分の仕事に持ち帰れるか。

意見ではなく、数字・式・基準を渡してください。
これが桁違いを分けた線です。


【6】ネタが切れない作り方

柱を4本立てて順番に回します。

1. お金（数字が出しやすい。いちばん伸びる）
2. 現場の裏側（読み物として強い）
3. 仕組み化・AI（新しさで拾われる）
4. 人・育成（共感で返信が付く）

同じ柱を2日続けない。朝＝お金、昼＝裏側、夜＝人、と時間で分けると迷いません。

ネタは、自分が人に説明して「へえ」と言われたことを全部メモするだけです。
自分には当たり前でも、外から見ると数字が付いている話は珍しい。そこが価値です。


【7】時間と本数

朝7:00／昼12:00／夜21:00。1日3本まで。

午前9〜12時と午後15〜18時は伸びにくい時間帯です。
4本以上出すと1本あたりの表示が落ちます。増やすより1本の質を上げてください。


【8】予約投稿の手順

1. 「新しいスレッド」を開く
2. 1本目にフックを入れる
3. 「スレッドに追加」を押して、2本目に本文を入れる
4. 右上の ⋯（もっと見る）→「日時を指定...」
5. カレンダーで日付 → 下にスクロールして時刻 →「完了」
6. 右下が「投稿」から「日時を指定」に変わるので、それを押す

制限が2つあります。
・予約できるのは25本まで
・7日先までしか指定できない（毎日1日ぶんずつ先が開きます）

予約した投稿は、あとから本文も時刻も直せます。そのときは最後が「更新」ボタンになります。
週末に7日ぶん21本まとめて入れると、平日は返信だけで回ります。


【9】週1回だけ見る数字

インサイトから各投稿を開くと出ます。この5つだけで十分です。

閲覧数 → 悪ければ1本目を書き直す
プロフィールへのアクセス → 悪ければ2本目の情報量を増やす
フォロー → 悪ければプロフィール文と固定ポストを直す
返信率 →「低い」なら最後の質問を答えやすいものに変える
見た人の興味・関心 → 業界の中で止まっていたらテーマを一段ひろげる

伸びた投稿の言い回しは、そのまま次に使い回してください。
当たった型は何度でも効きます。


【10】やってはいけないこと10個

1. 1本目にURLを貼る
2. 題名＋長文を1投稿に詰める
3. ハッシュタグを並べる
4. 外部リンクを何本も貼る
5. 1日4本以上出す
6. いいねの数で判断する（見るのは表示数）
7. 伸びない投稿をすぐ消す（データが消えます）
8. 業界用語を1行目に置く
9. 疑問形で始める
10. 毎回テーマを変える（柱は4本に固定）


【11】最初の7日間

1日目 プロフィールを4行で書き直す。固定ポストを1本作る
2日目 柱を4本決める。ネタを20個書き出す
3日目 7日ぶん21本を書いて、全部予約する
4〜7日目 朝、前日の返信に全部返す。それだけ
7日目 インサイトを開いて、伸びた1本の言い回しをメモする

4週間続けると、どの型が自分のアカウントで効くか分かります。あとは繰り返すだけです。
