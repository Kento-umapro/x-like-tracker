# フォロワー123人のアカウントが、1投稿で46万回表示された。Threads投稿の作り方

---

## ここから無料

先に、数字を出します。

| 項目 | 数値 | Threadsの判定 |
|---|---|---|
| 閲覧数 | **460,650** | 高い |
| 閲覧者 | 378,262 | 高い |
| プロフィールへのアクセス | 9,787 | 高い |
| この1投稿からのフォロー | **237** | 高い |

フォロワーは123人でした。広告はゼロ。インフルエンサーの拡散もゼロ。
**流入の99.8%が「ホーム」** です。つまり、こちらを知らない人にアルゴリズムが配った結果です。

同じアカウントで、同じ時期に、書き方だけを変えて比べたデータがあります。

| 書き方 | 表示数 |
|---|---|
| 題名＋本文を1投稿に全部入れる | 254 / 287 / 373 / 687 |
| この指示書のやり方 | 10,441 / 12,470 / 59,495 / **460,650** |

**桁が3つ違います。**

内容は変えていません。1投稿の「分け方」と「1行目」を変えただけです。

### この指示書に書いてあること

- 1投稿を2つに分ける理由と、その分け方
- 1行目（フック）の型。実際に46万回いった文をそのまま載せています
- 2本目に何を書くか。250〜320字のテンプレート
- **伸びた投稿と伸びなかった投稿で「見た人の中身」がどう違ったか**（ここが核心です）
- 最後の1行の置き方。返信率が0%だった原因と直し方
- 投稿する時間と本数
- 予約投稿の手順（画面の操作まで）
- 週1回だけ見る数字と、その読み方
- やってはいけないこと10個

### こういう人向けです

- Threadsを始めたが、表示数が3桁から動かない
- フォロワーが増えず、何を直せばいいか分からない
- X（旧Twitter）と同じ書き方をして、伸びていない
- 発信から仕事につなげたいが、入口が作れていない

### こういう人には向きません

- すでにフォロワーが1万人を超えている
- 裏技やツールでの自動化を探している（そういう話は書いていません）
- 「絶対に伸びる」という保証がほしい

正直に書きます。**46万回は1投稿だけです。** 同じ型で出した他の投稿は1万〜6万でした。
運の要素は確実にあります。この指示書でできるのは、**当たりくじを引ける場所に立つこと**までです。
ただし、3桁で止まっていたものが1万を下回らなくなったのは事実で、その差の作り方を全部書いています。

ここから先が本編です。全部で約6,000字。読んで、今日の夜の1本から使えます。

---

## ここから有料

### 1. 結論だけ先に

1. **1投稿を2つに分ける。** 1本目＝フック（短い）、2本目＝返信欄に本文（長い）
2. **1本目にURLを貼らない。** リンクはプロフィールか固定ポストに集約する
3. **1本目で「持ち帰れる数字か式」を予告する**
4. **2本目の最後を質問で終える**
5. 1日3本。朝7時・昼12時・夜21時

この5つだけです。以下、理由と具体的な書き方を順番に書きます。

---

### 2. なぜ2つに分けるのか

Threadsは、**1本目の数行だけを見て「配るかどうか」を決めています。**

長い本文を1本目に置くと、読者はそこで読み終えるか、途中でスクロールします。
どちらにしても「最後まで見られなかった投稿」として扱われ、配信が止まります。

分けると、1本目は3行で読み終わります。読み切られた投稿として扱われ、続きが気になった人が返信欄を開く。
**Threadsは返信欄が開かれた回数も見ています。**

実測では、これだけで表示数が40倍変わりました。

---

### 3. 1本目（フック）の書き方

**2〜3行。50字以内。URLなし。絵文字なし。ハッシュタグなし。**

#### 型

```
①常識をひっくり返す断定（1行）
②数字か式が出てくることの予告（1〜2行）
```

#### 46万回いった文（そのまま）

```
損益分岐点を出せないまま店を開ける人が、まだ多いです。
式はひとつだけで、紙1枚で出ます。
出し方を書きます。
```

1行目で「できていない人が多い」と断定し、2行目で「式がある」「紙1枚」と予告し、3行目で引いています。

#### 効いた言い回し（そのまま使えます）

- 「〜と思われていますが、違います。」
- 「〜していない人が、まだ多いです。」
- 「〜したら、〜になりました。」（結果を先に出す）
- 「式はひとつだけです」
- 「3つあります」
- 「紙1枚で出ます」

#### 1行目でやってはいけないこと

- **業界用語を置く。** 読み手の99%は業界の外にいます
- **疑問文にする。** 「〜ですよね？」は弱い。断定してください
- **絵文字。** 伸びた投稿に1つも入っていません
- **URL。** ここに貼ると、そこで思考が止まってスクロールされます

---

### 4. 2本目（コメント）の書き方

**250〜320字。①②③の3点か、計算をひとつ。**

#### 必ず入れるもの

**(a) 実際の数字か計算式**

読んだ人がその場で自分に当てはめられるものを置きます。

```
固定費 ÷ 粗利率 = 損益分岐点売上。
固定費が月180万、原価30%なら、180 ÷ 0.7 = 約257万。
営業26日で割ると、1日あたり約10万。
```

ここまで書くと、読んだ人は自分の数字を入れ始めます。それが滞在時間になります。

**(b) 最後の1行を質問にする**

```
あなたの店のFL、いま何%ですか。
```

#### なぜ質問が要るか

46万回いった投稿でも、**返信率は0%。Threadsの判定は「低い」でした。**

表示が伸びても、返信が付かないと次の投稿が伸びません。Threadsは返信をいちばん重く見ています。
質問を1行置くだけで、ここが動きます。いちばん費用対効果の高い1行です。

---

### 5. 核心：専門家の外に出す

ここがこの指示書でいちばん大事な部分です。

伸びた投稿と、伸びなかった投稿で、**見た人の中身が違いました。**

| 投稿 | 表示 | 見た人の興味・関心 |
|---|---|---|
| 損益分岐点（式がある） | 460,650 | 猫・カフェ・筋トレ・旅行・美容 |
| 潰れる店は味で潰れない | 59,495 | カフェ・飲食店経営・飲食店・グルメ |
| ルールを増やすと組織が弱くなる | 10,441 | － |

**伸びたほうだけ、業界の外に出ています。**

2番目の投稿も内容は良いのですが、「飲食に興味がある人」の中で止まりました。
3番目は意見としては正しいのですが、**持ち帰れるものがないので止まりました。**

判定基準はこれだけです。

> **その話は、業界を知らない人が読んで、自分の仕事に持ち帰れるか。**

- 「損益分岐点の出し方」→ 誰でも使える ◎
- 「ルールを増やすと組織が弱くなる」→ 意見。持ち帰れない △
- 「出数の集計を自動化した」→ 業界の中の話 △

**意見ではなく、数字・式・基準を渡してください。** これが40倍と桁違いを分けた線です。

---

### 6. ネタが切れない作り方

柱を4本立てて、順番に回します。

1. **お金**（数字が出しやすい。いちばん伸びる）
2. **現場の裏側**（読み物として強い）
3. **仕組み化・AI**（新しさで拾われる）
4. **人・育成**（共感で返信が付く）

同じ柱を2日続けない。朝＝お金、昼＝裏側、夜＝人、のように時間で分けると迷いません。

ネタの出し方は単純で、**自分が人に説明して「へえ」と言われたこと**を全部メモしておくだけです。
自分には当たり前でも、外から見ると数字が付いている話は珍しい。そこが価値になります。

---

### 7. 投稿する時間と本数

**朝7:00 / 昼12:00 / 夜21:00。1日3本まで。**

午前9〜12時と、午後15〜18時は伸びにくい時間帯です。
4本以上出すと1本あたりの表示が落ちます。増やすより、1本の質を上げてください。

---

### 8. 予約投稿の手順

1. 「新しいスレッド」を開く
2. 1本目にフックを入れる
3. **「スレッドに追加」** を押して、2本目に本文を入れる
4. 右上の **⋯（もっと見る）→「日時を指定...」**
5. カレンダーで日付を選ぶ → 下にスクロールして時刻を入れる → **「完了」**
6. 右下のボタンが「投稿」から **「日時を指定」** に変わるので、それを押す

#### 知っておくべき制限

- **予約できるのは25本まで**
- **7日先までしか指定できない**（毎日、1日ぶんずつ先が開きます）
- 予約した投稿は、あとから本文も時刻も直せます。直すときは最後のボタンが「更新」になります

週末に7日ぶん（21本）まとめて入れておくと、平日は返信だけで回ります。

---

### 9. 週1回だけ見る数字

インサイト → 各投稿を開くと出ます。全部見る必要はありません。この5つだけです。

| 見る数字 | 意味 | 悪いときにやること |
|---|---|---|
| 閲覧数 | 1本目が効いたか | フックを書き直す |
| プロフィールへのアクセス | 続きを読みたいと思わせたか | 2本目の情報量を増やす |
| フォロー | 出口が機能しているか | プロフィール文と固定ポストを直す |
| **返信率** | 「低い」なら質問が弱い | 最後の質問を、答えやすいものに変える |
| **見た人の興味・関心** | 業界の外に出られているか | テーマを一段ひろげる |

**伸びた投稿の言い回しは、そのまま次に使い回してください。** 当たった型は何度でも効きます。

---

### 10. やってはいけないこと10個

1. 1本目にURLを貼る
2. 題名＋長文を1投稿に詰める
3. ハッシュタグを並べる
4. 外部リンクを何本も貼る
5. 1日4本以上出す
6. いいねの数で良し悪しを判断する（見るのは表示数）
7. 伸びない投稿をすぐ消す（データが消えます）
8. 業界用語を1行目に置く
9. 疑問形で始める
10. 毎回テーマを変える（柱を4本に固定する）

---

### 11. 最初の7日間にやること

| 日 | やること |
|---|---|
| 1日目 | プロフィールを4行で書き直す。固定ポストを1本作る |
| 2日目 | 柱を4本決める。ネタを20個書き出す |
| 3日目 | 7日ぶん21本を書いて、全部予約する |
| 4〜7日目 | 朝、前日の返信に全部返す。それだけ |
| 7日目 | インサイトを開いて、伸びた1本の言い回しをメモする |

これを4週間続けると、どの型が自分のアカウントで効くかが分かります。
あとはそれを繰り返すだけです。

---

### おわりに

この指示書は、1つのアカウントで実際に起きたことをそのまま書いたものです。
数字はすべて実測で、推測は推測と書きました。

うまくいかないときは、だいたい「1行目が業界の中の言葉になっている」か「持ち帰れるものがない」かのどちらかです。
そのときはこの記事の5章に戻ってください。

質問があれば、記事のコメントかThreadsの返信に書いてください。できる範囲で答えます。
