# 固定ポストの差し替え案 と MD指示書シリーズの設計

## A. 固定ポスト（note公開後に差し替え）

いまの固定ポストはLINEのチェックシート導線です。これをnoteの形に変えます。
**noteのURLが出てから入れ替えます。** 以下は入稿待ちの原稿です。

### 1本目（フック・URLなし）

```
フォロワー123人のアカウントが、1投稿で46万回表示されました。
広告ゼロ、拡散ゼロ。流入の99.8%がホームです。
何を変えたのかを書きます。
```

### 2本目（返信欄・ここにリンク）

```
変えたのは2つだけです。

①1投稿を2つに分けた。1本目はフックだけ3行、本文は返信欄に置く。
②1行目で「持ち帰れる数字か式」を予告した。

題名＋長文を1投稿に入れていたときは254〜687回。
この型に変えてから、10,441／12,470／59,495／460,650。桁が3つ変わりました。

伸びた投稿と伸びなかった投稿で、見た人の興味まで違っていました。
そこがいちばん大事なところなので、数字ごと全部まとめました。

→（noteのURL）
```

### プロフィール4行目の差し替え

いま：`開業前に見るチェックシートは固定ポストから`
↓
案：`Threadsの伸ばし方は固定ポストから`

**LINEの無料チェックシートの出口が固定ポストから外れます。**
残すなら、プロフィール文を次のようにして両方を残せます。

```
もんじゃ・鉄板焼酒場「どてっぱん」12店舗の中の人
元・現場監督 → 飲食5年目
店の裏側と、開業のお金の話を数字で書きます
Threadsの伸ばし方は固定ポスト／開業チェックシートはLINEで無料
```

→ ただしプロフィールにURLは1本しか置けないので、**どちらを主にするかは決めてください。**

## B. 価格（note相場の実測）

noteで「Threads 運用」「Threads フォロワー 増やす」「スレッズ 攻略 マニュアル」を有料記事で検索し、
表示されていた販売価格を全部拾いました。**n=28本**（うち2万円超の3本は講座・サロン型なので除外）。

| 統計 | 金額 | 7掛け |
|---|---|---|
| 平均（n=25） | ¥2,442 | **¥1,709** |
| 中央値（n=25） | ¥980 | ¥686 |
| 平均（500円以上・n=21） | ¥2,857 | ¥2,000 |
| 中央値（500円以上・n=21） | ¥2,000 | ¥1,400 |

実際の分布：100 / 240 / 300 / 400 / 500×4 / 780 / 980×4 / 1,980 / 2,000 / 2,980×5 / 3,500 / 4,980×2 / 10,480×2

### 結論：**¥1,680**

- ご指示の「平均の7掛け」= ¥1,709 に最も近いキリのいい数字
- ¥980帯（日記・体験談）より明確に上、¥2,980帯（マニュアル）よりわずかに下
- 「ちゃんとしたマニュアルなのに、少し安い」という位置に入ります

**もし実績を先に積みたいなら、最初の30部だけ ¥980 → 以降 ¥1,680 の段階値上げ**も有効です。
noteは「○部突破」を表示できるので、部数が売れる理由になります。

## C. MD指示書シリーズの設計

「実際に自分でやって、数字が出たことだけをMDで売る」。これを型にします。

### 1本あたりの構成（固定）

| ブロック | 中身 | 目安 |
|---|---|---|
| 無料部 | 実測の数字（表） → 何が書いてあるか → 誰向け／誰に向かないか → 正直な限界 | 1,000〜1,200字 |
| 有料部 | 結論5行 → 理由 → 型とテンプレ → 核心1つ → 手順 → 見る数字 → やってはいけないこと → 最初の7日間 | 3,000〜5,000字 |

**無料部に必ず「向かない人」と「限界」を書く。** 返金・低評価が減り、結果として売れます。

### 出す順番（在庫）

| # | テーマ | 根拠にできる実測 | 状態 |
|---|---|---|---|
| 1 | Threads投稿の作り方 | 46万回・フォロー237 | **原稿あり** |
| 2 | Xの自動いいね運用 | 日次ログ・フォロワー推移 | 素材あり |
| 3 | 飲食店の数字の見方（FL・損益分岐点・坪効率） | 12店舗の実数 | 素材あり |
| 4 | 売上予報をAIで作る | 60日予報・8店舗 | 素材あり |
| 5 | 出数集計の自動化で廃棄を減らす | ダイニーPOS連携 | 素材あり |
| 6 | 開業前チェックシートの使い方 | 既存PDF | 素材あり |

### 売り方

1. Threadsで**その指示書の中身を1本だけ無料で出す**（これが広告になる）
2. 伸びた投稿の固定ポストから note へ
3. note の最後から LINE へ（個別相談・AI指南の入口）

**順番が逆だと売れません。** 先に価値を出して、後ろに出口を置く。
