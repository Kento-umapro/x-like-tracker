# Threads 投稿の指示書（フック＋コメント型）

このやり方で、フォロワー100人台のアカウントが1投稿46万回表示・1日でフォロー+237を取りました。
以下はその実測にもとづく手順です。アカウントを問わず、そのまま使えます。

---

## 0. 結論だけ先に

1. **1投稿を2つに分ける。** 1本目＝フック（短い）、2本目＝返信欄に本文（長い）。
2. **1本目にURLを貼らない。** リンクはプロフィールか固定ポストに集約する。
3. **1本目で「持ち帰れる数字か式」を予告する。**
4. **2本目の最後を質問で終える。**
5. 1日3本。朝7時・昼12時・夜21時。

---

## 1. なぜ2つに分けるのか（実測）

同じアカウントで比べた結果です。

| 型 | 表示数 |
|---|---|
| 【題名】＋本文を1投稿に全部入れる | 254 / 287 / 373 / 687 |
| フック＋コメントの2連投 | 10,441 / 12,470 / 59,495 / **460,650** |

**桁が違います。** いいねは題名型のほうが付きますが、見られる数は比較になりません。
判断はいいねではなく**表示数**でしてください。

理由は単純で、Threadsは1本目の数行だけを見て配るかどうかを決めているからです。
長い本文を1本目に置くと、そこで読むのをやめられ、配信が止まります。

---

## 2. 1本目（フック）の書き方

**2〜3行。50字以内。URLなし。**

### 型
```
①常識をひっくり返す断定（1行）
②そのあと、数字か式が出てくることを予告（1〜2行）
```

### 実際に46万回いった文
```
損益分岐点を出せないまま店を開ける人が、まだ多いです。
式はひとつだけで、紙1枚で出ます。
出し方を書きます。
```

### 効いた言い回し
- 「〜と思われていますが、違います。」
- 「〜していない人が、まだ多いです。」
- 「〜したら、〜になりました。」（結果を先に出す）
- 「式はひとつだけです」「3つあります」「紙1枚で出ます」

### やらないこと
- 1行目に業界用語を置く（「FL」「出数」「坪効率」など）
- 1行目を疑問文にする
- 絵文字、ハッシュタグ
- 1本目にURL

---

## 3. 2本目（コメント）の書き方

**250〜320字。①②③の3点か、計算を1つ。**

### 絶対に入れるもの
- **実際の数字か計算式。** 読んだ人がその場で自分に当てはめられるもの。
  例：`固定費 ÷ 粗利率 = 損益分岐点売上。固定費180万・原価30%なら、180 ÷ 0.7 = 約257万。`
- **最後の1行を質問にする。** 例：「あなたの店のFL、いま何%ですか。」

### なぜ質問が要るか
Threadsは返信を強く評価します。46万回の投稿でも**返信率0%で「低い」と判定**されていました。
表示が伸びても、返信がないと次が伸びません。質問を置くだけで変わります。

---

## 4. いちばん大事なこと：専門家の外に出す

伸びた投稿と伸びなかった投稿で、**見た人の中身**が違いました。

| 投稿 | 表示 | 見た人の興味 |
|---|---|---|
| 損益分岐点（式がある） | 460,650 | 猫・カフェ・筋トレ・旅行・美容 |
| 潰れる店は味で潰れない | 59,495 | カフェ・飲食店経営・飲食店・グルメ |

**伸びたほうだけ、業界の外に出ています。**
流入は**ホームから99.8%**。つまりフォロワーではなく、あなたを知らない人に配られた結果です。

だから基準はこれです。

> **その話は、業界を知らない人が読んで、自分の仕事に持ち帰れるか。**

- 「損益分岐点」→ 誰でも使える ◎
- 「ルールを増やすと組織が弱くなる」→ 意見だけで持ち帰れない △（1万回で止まった）
- 「出数の集計を自動化した」→ 業界の中の話 △

意見ではなく、**数字・式・基準**を渡してください。

## 5. ネタの柱

4つを順番に回すと切れません。

1. **お金**（数字が出しやすい・いちばん伸びる）
2. **現場の裏側**（読み物として強い）
3. **AI・仕組み化**（新しさで拾われる）
4. **人・育成**（共感で返信が付く）

同じ柱を2日続けない。朝＝お金、昼＝裏側、夜＝人、のように分けると楽です。

---

## 6. 投稿時間

**朝7:00 / 昼12:00 / 夜21:00。** 1日3本まで。
午前9〜12時と午後15〜18時は伸びにくい時間帯です。

---

## 7. 予約投稿の手順（Threadsのウェブ版）

1. 「新しいスレッド」を開く
2. 1本目にフックを入れる
3. **「スレッドに追加」**を押して、2本目に本文を入れる
4. 右上の **⋯（もっと見る）→「日時を指定...」**
5. カレンダーで日付を選ぶ → 下にスクロールして時刻を入れる → **「完了」**
6. 右下のボタンが「投稿」から **「日時を指定」** に変わるので、それを押す

### 制限
- **予約できるのは25本まで**
- **7日先までしか指定できない**（毎日、1日ぶんずつ先が開く）
- 予約した投稿はあとから本文も時刻も直せる。直すときは最後が「更新」ボタンになる

---

## 8. 週に1回みる数字

インサイト → 各投稿を開くと出ます。

| 見る数字 | 意味 |
|---|---|
| 閲覧数 | 1本目が効いたか |
| プロフィールへのアクセス | 「この人の他も読みたい」と思わせたか |
| フォロー | 出口が機能しているか |
| **返信率** | ここが「低い」なら質問が弱い |
| 見た人の興味・関心 | 業界の外に出られているか |

**伸びた投稿は、言い回しをそのまま次に使い回してください。** 当たった型は何度でも効きます。

---

## 9. 1日の運用（5分）

- 朝：前日の返信に全部返す（返信率が上がる＝次が伸びる）
- 予約が7日先まで埋まっているか確認。空いていたら足す
- 週1回だけ、上の表を見て伸びた型をメモする

---

## 10. やってはいけないこと

- 1本目にURLを貼る
- 題名（【】）＋長文を1投稿に詰める
- ハッシュタグを並べる
- 外部リンクを何本も貼る
- 1日4本以上
- いいねの数で良し悪しを判断する（見るのは表示数）
